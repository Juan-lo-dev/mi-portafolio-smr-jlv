Módulo: Ofimática

En este módulo se desarrollan habilidades para utilizar herramientas ofimáticas como procesadores de texto, hojas de cálculo, presentaciones y bases de datos. Es fundamental para la creación de documentos profesionales.

Competencias Adquiridas

Procesador de Textos

Dominio de Microsoft Word y Google Docs para crear documentos profesionales.

Hojas de Cálculo

Creación de fórmulas, gráficos y uso de funciones en Excel o Google Sheets.

Presentaciones

Elaboración de presentaciones visuales con PowerPoint o Google Slides.

Bases de Datos Básicas

Uso básico de Microsoft Access u hojas de cálculo como base de datos.

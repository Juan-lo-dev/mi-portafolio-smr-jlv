Servicios en Red

Servidor DHCP

Asigna direcciones IP automáticamente a los dispositivos conectados a una red.

Servidor DNS

Convierte nombres de dominio legibles en direcciones IP numéricas.

Servidor Web

Entrega páginas web a los usuarios a través del protocolo HTTP o HTTPS.

Servidor FTP

Permite la transferencia de archivos entre un cliente y un servidor en red.

Servidor de Correo

Gestiona el envío y recepción de correos electrónicos entre usuarios.

Servidor Proxy

Actúa como intermediario entre los clientes e Internet para mejorar seguridad y rendimiento.
